# Owner review required before public release

Private staging is not public authorization. The maintainer must personally confirm:

- [ ] I am authorized to open-source **this independent code**, with no unlicensed employer, client, or third-party IP.
- [ ] I approve the MIT license attribution (`Copyright (c) 2026 The contributors`).
- [ ] I have reviewed every tracked file and Git history for secrets, customer references, invoices, contact details, and accidental private content.
- [ ] I have configured a private security disclosure channel and checked GitHub Actions permissions.
- [ ] I have inspected npm's package name and exact tarball contents; no package has been published without permission.
- [ ] I authorize making **only this repository** public in GitHub, separately from Pocki and Duewise.

An unchecked box is a release blocker. Anthropic qualification depends on actual external impact, not these checklist items.
