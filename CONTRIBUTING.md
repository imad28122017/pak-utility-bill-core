# Contributing

Contributions are welcome after this package is publicly launched. Please submit tests with parsing improvements and use **invented** sample invoices only; redact personal information from bug reports. Keep all logic deterministic, side-effect-free, offline by default and conservative in the presence of conflicting/missing data. Changes that access live providers, perform network requests, store credentials, or add telemetry are out of scope for the core package.

New formats require test fixtures, a clear provider source and documentation. Do not upload documents sourced from real customers. Maintain backward compatibility where possible.
